Sales Data Analysis Dashboard

Project Overview

This project analyzes Superstore sales data using Python and Power BI to identify sales trends, product performance, regional performance, and key business insights.

Objectives

- Clean and prepare sales data.
- Analyze sales, profit, orders, and units sold.
- Identify top-performing products, categories, and regions.
- Create visualizations and a Power BI dashboard.
- Generate actionable business insights.

Technologies Used

- Python
- Pandas and NumPy
- Matplotlib
- Power BI
- Git and GitHub

Project Structure

- "data/raw/" — Original dataset
- "data/cleaned/" — Cleaned sales dataset
- "notebooks/" — Data inspection
- "analysis/" — Data cleaning, analysis, and visualization scripts
- "powerbi/" — Power BI dashboard
- "reports/" — Analysis outputs, charts, insights, and report
- "presentation/" — Project presentation outline

Key Results

- Total Sales: $2,326,534.35
- Total Profit: $292,296.81
- Total Orders: 5,111
- Unique Products: 1,862
- Units Sold: 38,654
- Overall Profit Margin: Approximately 12.6%

Dashboard

The Power BI dashboard summarizes key performance indicators, monthly sales trends, top products, regional sales, and category sales.

Business Insights

The analysis identified the West as the leading sales region, Technology as the leading category, and Canon imageCLASS 2200 Advanced Copier as the top product by sales.

Data note: The supplied dataset includes November and December 2026 records. These future-dated records should be validated before drawing time-based conclusions.
